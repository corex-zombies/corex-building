# COREX Building — دليل التركيب والاستخدام

[English](../README.md) · [الأصول](https://github.com/corex-zombies/corex-building-assets) · [تحميل الحزمة الكاملة](https://github.com/corex-zombies/corex-building/releases/latest)

نظام بناء لمنظومة COREX، يضم 28 قطعة بثلاث خامات: الخشب والحجر والحديد، بإجمالي 84 موديلًا وآيتيمًا. يشمل مساعدات وضع القطع، الحفظ، الملكية، التطوير والأبواب المتحركة مع كلمات مرور اختيارية.

## المتطلبات والتركيب

تحتاج سيرفر COREX مع تفعيل OneSync، وتشغيل `corex-core` و`corex-capabilities` و`corex-content` و`ox_lib` و`oxmysql` ومزود مخزون متوافق. مورد `ox_target` اختياري؛ الأبواب تعمل أيضًا بزر التفاعل.

1. نزّل الحزمة الكاملة من صفحة الإصدارات، أو نزّل مستودعي السكريبت والأصول.
2. ضع `corex-building` داخل `resources/[corex]/`، و`corex-building-assets` داخل `resources/[assets]/`. حافظ على الاسمين كما هما، واحذف لاحقة `-main` إذا نزّلت ملفات المصدر من GitHub.
3. انسخ صور `corex-building/icons/` إلى `corex-inventory/html/images/`. الحزمة الكاملة تتضمن الصور في هذا المسار؛ لا تستبدل ملفات كود المخزون. مع مخزون خارجي، ضع الصور في مجلد الصور الخاص به.
4. شغّل الموردين بعد المنظومة والمخزون وموارد ox المطلوبة:

```cfg
ensure corex-building-assets
ensure corex-building
```

لتفعيل العربية، عدّل `config.lua`:

```lua
Config.Locale = 'ar'
```

ينشئ السكريبت جداول قاعدة البيانات تلقائيًا عندما يكون `Config.Database.autoCreate = true`. للاستيراد اليدوي، استخدم `sql/corex_building.sql` وعطّل الإنشاء التلقائي. عند اكتمال التشغيل تظهر رسالة `Ready: 84 usable building items`.

تُسجّل الآيتيمات عبر COREX Content بصيغة `build_<tier>_<piece>`، مثل `build_wood_foundation`. المخازن الخارجية ذات القوائم الثابتة قد تحتاج تعريفات إضافية؛ يمكن توليد تعريفات ox_inventory من كونسول السيرفر:

```text
corex_content_snippet corex-building ox_inventory
```

إضافة الآيتيمات إلى المتاجر والكرافت واللوت تكون من إعدادات مواردك الحالية.

## التحكم

| الزر أو الأمر | الوظيفة |
| --- | --- |
| استعمال آيتيم البناء | بدء المعاينة الشفافة |
| كليك يسار | تثبيت القطعة المعروضة |
| كليك يمين / Escape | إلغاء |
| سكرول الماوس | تدوير القطعة الحرة أو التنقل بين نقاط التركيب المتوافقة |
| F9 / `/buildingfree` | تبديل الوضع الحر للأرضيات |
| E / `/buildingdoor` | فتح أو إغلاق الباب القريب |
| G / `/building` | إدارة القطعة القريبة التي تملكها |

يمكن تغيير الأزرار والأوامر من الكونفيغ. زر Shift للجري. تظهر مساعدات شفافة في مواقع التركيب المناسبة، وتوضح المعاينة سبب الرفض عند وجوده. الأبواب تحتاج إطارها المناسب، والطوابق والأسقف تحتاج دعامات متوافقة.

أمر `/building` متاح لصاحب البناء دون صلاحية أدمن. يسمح بتطوير قطعته، وحذف القطع التي لا يسبب حذفها فقدان دعم القطع التابعة، وتغيير باسورد الباب. التطوير يستهلك آيتيم القطعة من الخامة التالية.

مالك الباب يستطيع فتحه دون إدخال الباسورد افتراضيًا، بينما يُطلب من الآخرين إدخاله. الفتح والإغلاق بحركة تدريجية حول المفصلة. تُحفظ كلمات المرور كبصمات scrypt، ولا تُحفظ كنص واضح.

## الإعدادات

النسخة المنشورة تسمح بالبناء داخل السيف زون، وفحص استواء الأرض والعوائق الاختياري معطّل افتراضيًا. تتحكم بذلك إعدادات `blockSafeZones` و`validateTerrain` و`checkWorldCollision`. فحوص الملكية والدعامات ونقاط التركيب والآيتيمات تظل فعالة.

`Config.Guides` للمساعدات، و`Config.Streaming` لمدى عرض المباني، و`Config.Doors` للأبواب، و`Config.Management` لإدارة المالك. إعدادات السلالم تتضمن مواضع التركيب، دون نظام تسلق مخصص.

بعد تحديث ملفات الموديلات، أغلق FiveM وافتحه من جديد لتحميل الأصول المحدثة.

## أدوات الأدمن

أمر `/buildkit wood` أو `/buildkit stone` أو `/buildkit steel` يوفر قطع الخامة حسب سعة المخزون. يحتاج صلاحية `corex.admin` افتراضيًا. أمر `/buildkit wood reset` يبدأ دورة تزويد جديدة ويكمل النواقص دون مضاعفة الموجود.

راجع [دليل تكامل السيرفر](server-integration.md) لأوامر الإدارة البرمجية والتعامل مع عمليات الحفظ غير المؤكدة.

المجلدات المنشورة تحتوي ملفات التشغيل والتوثيق فقط. ملف JavaScript الخاص بكلمات المرور وملف JSON الخاص بهندسة البناء مطلوبان للتشغيل. لا تحتاج تثبيت Python أو أدوات بناء لتشغيل الموردين.
